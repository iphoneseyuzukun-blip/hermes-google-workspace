プライバシーポリシー

1. 対象

本ポリシーは、個人利用向け連携「Hermes Google Workspace」による Google ユーザーデータの取り扱いを説明します。利用者本人が管理する環境での利用を想定しています。

2. アクセスする情報と目的

利用者が許可した権限の範囲で、次の情報にアクセスします。

  • Gmail のメール本文・添付ファイル・送受信者・件名・ラベル等：メールの確認、要約、下書き、依頼された送信・整理のため。
  • 個人用 Google Calendar の予定・日時・説明等：予定の確認と、依頼・承認された予定管理のため。
  • Drive、Docs、Sheets のファイル情報・内容：検索、確認、要約、依頼された作成・編集のため。
  • 学校用 Classroom の授業、課題、資料、お知らせ、自分の提出状況・閲覧可能な成績：学習上の確認や整理のため。Classroom は閲覧専用です。
  • OAuth の認証情報、アカウント識別情報：認証の維持と、個人用・学校用アカウントの取り違え防止のため。

依頼に必要な情報だけを扱い、広告配信やデータ販売を目的として利用しません。

3. 保存

OAuth 認証情報は、利用者が管理する PC 上のアカウント別領域に保存します。この公開サイトや公開リポジトリには保存しません。

処理した内容は、利用者の指示による成果物のほか、Hermes の会話履歴・作業ファイル・診断ログ等に残る場合があります。保存期間は利用環境や保存先の設定に依存します。本アプリは、すべての履歴が自動消去されることや、保存データが常に暗号化されることを保証しません。

4. 外部サービスへの送信

Google API との通信に加え、依頼を処理するため、必要な情報が利用者の選択した AI モデル提供者や利用中のチャットサービスへ送信される場合があります。これらのサービスにおける保存・処理条件は、各サービスの規約・プライバシーポリシーや契約・設定にも依存します。すべての処理が PC 内だけで完結するものではありません。

メール送信やファイル共有など、利用者が依頼・承認した操作では、その宛先・共有先に必要な情報を送信します。学校の管理規程や第三者の権利に反する情報の送信を許可するものではありません。

5. Google ユーザーデータの利用制限

Google API から取得した情報の利用および他のアプリへの転送について、Limited Use の要件を含む Google API Services User Data Policy を運用上の基準とします。Google ユーザーデータを、汎用 AI・機械学習モデルの学習または改善の目的で利用・転送しません。外部サービスへ Google ユーザーデータを送信する前に、この条件を満たす提供者・契約・設定であることの確認を運用条件とします。本サイトは、個々の外部サービスの設定を監査・保証するものではありません。

6. 認証の取り消しと削除

利用者は Google アカウントの接続管理 からアプリのアクセス権を取り消せます。アクセス権の取り消しだけでは、PC 上の認証ファイル、会話履歴、成果物や外部サービスに残ったデータは自動削除されません。削除が必要な場合は、各保存先とバックアップを確認し、対象を指定して削除します。

7. 安全管理

認証情報を公開しないこと、アカウントを分離すること、操作内容に応じて利用者の承認を得ることを基本とします。ただし、完全な安全性を保証するものではありません。

8. このサイトの閲覧

このサイトに利用者の Google データを掲載することはありません。公開先サービスが、サイトへのアクセスに関する技術情報を、そのサービスのポリシーに従って処理する場合があります。このサイトの公開先は GitHub Pages です。GitHubのプライバシーに関する声明も参照してください。

9. 連絡先・変更

お問い合わせ先：GitHubの問い合わせ窓口（公開されるため、個人情報・認証情報は投稿しないでください）

取り扱う情報や利用先を変更する場合は、本ポリシーも更新します。
